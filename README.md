# PhoneBook Application (Java Console)

A simple console-based PhoneBook application written in Java. It uses a `HashMap` to store contacts, where the **phone number** is the key and the **contact name** is the value. This allows fast O(1) lookup, insertion, and deletion.

---

## ✨ Features

- ✅ Add new contacts (phone number → name)
- ✅ Search contacts by phone number (instant lookup)
- ✅ Delete contacts by phone number
- ✅ List all saved contacts
- ✅ Handle **duplicate phone numbers** gracefully
- ✅ Validate **invalid input** (empty fields, non-10-digit numbers)
- ✅ Simple text-based menu for user interaction

---

## 🛠️ Technologies Used

- **Language:** Java (JDK 21)
- **IDE:** Eclipse
- **Data Structure:** `HashMap<String, String>`
- **Input Handling:** `Scanner`
- **Version Control:** Git + GitHub
